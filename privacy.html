Политика конфиденциальности

Последнее обновление: 3 мая 2026

Настоящая Политика конфиденциальности определяет порядок обработки информации при использовании сайта Домашней страницы, включая цели обработки, применяемые технологии хранения данных и способы управления пользовательскими настройками.

1. Владелец сайта

Владелец проекта: Артём Мандрин.

Контакт по вопросам обработки данных: mandrina37@gmail.com.

2. Как работает сайт

Сайт является статическим веб-проектом, размещённым на платформе GitHub Pages. Проект не использует собственный сервер приложений (backend), базу пользовательских аккаунтов или механизм авторизации.

3. Какие данные могут обрабатываться

  • IP-адрес и технические параметры браузера (в пределах работы GitHub Pages/CDN и внешних API).
  • Параметры интерфейса (тема оформления, язык, отображение блоков).
  • Пользовательские шорткаты (названия, ссылки, иконки).
  • Локальная история поисковых запросов.
  • Указанный город для погодного виджета.
  • Пользовательский фон и выбранный шаблон.
  • Порядок отображения виджетов.
  • Локальные кеши данных погоды, валют и IP/региона.

4. Где хранятся пользовательские данные

Данные пользовательских настроек сохраняются локально в браузере пользователя (localStorage и Cache Storage при использовании Service Worker).

Владелец сайта не имеет прямого доступа к localStorage пользователя и не получает указанные данные на собственный сервер.

5. Используемые сторонние сервисы

  • GitHub Pages — размещение и доставка статических файлов сайта.
  • Google Suggest (`suggestqueries.google.com`) — поисковые подсказки (при включённой функции).
  • Open-Meteo (`api.open-meteo.com`, `geocoding-api.open-meteo.com`) — данные погоды и геокодирование (при включённом погодном виджете).
  • `www.cbr-xml-daily.ru` — данные для виджета курсов валют (при включённой функции).
  • `ipapi.co`, `ipwho.is`, `ipinfo.io`, `api.ipify.org`, `nominatim.openstreetmap.org` — определение IP/региона и локализация города (при включённом IP/регион виджете).

6. Цели обработки данных

  • Сохранение пользовательских параметров интерфейса и персонализации страницы.
  • Отображение шорткатов и локальной истории поиска пользователя.
  • Получение данных внешних виджетов (погода, валюты, IP/регион) в рамках включённых пользователем функций.
  • Повышение скорости загрузки за счёт локального кеширования статических и сервисных данных.

7. Управление и удаление данных

  • В интерфейсе сайта доступны настройки отключения необязательных функций и сброса пользовательских данных.
  • Дополнительно данные могут быть удалены стандартными средствами браузера (cookies, localStorage, cache, Service Worker).
